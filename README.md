# NVIDIA Fans Club

A responsive, static fan-made GeForce GPU archive website.

## Run locally
Open `index.html` in a modern browser. For best results, serve this folder with any static web server.

## Deploy
Upload the entire `nvidia-fans-club` folder to GitHub Pages, Netlify, Vercel (static), or any web host.

## Included
- NVIDIA-inspired dark theme, green circuit grid, animated particles and loading screen
- User-provided logo asset at `assets/nvidia-fans-logo.jpg`
- Search, generation filters, sorting and side-by-side reference price comparison
- Discord invite link
- C++ showcase section

## Important notes
This is an independent fan project, not an official NVIDIA website or store. Product imagery is represented by original CSS GPU illustrations rather than official product photography. The catalogue is a curated desktop GeForce selection, not every laptop/OEM/workstation/regional SKU ever released. INR figures are approximate illustrative reference prices, not live quotes or verified stock. Confirm current prices, availability, seller and warranty before relying on them.
